# PHAROS Frontend

Interface web do piloto no Capão Redondo com Next.js e TypeScript.

```sh
npm ci
npm run dev
```

Abra [localhost:3000](http://localhost:3000). Os trajetos e relatos são demonstrativos e ficam no frontend.

Para verificar o projeto, execute `npm run typecheck` e `npm run build`.

O cenário padrão vai da Praça do Jardim Comercial ao Metrô Capão Redondo. Inverta origem e destino para inspecionar o estado sem alternativas cadastradas. Envio de relatos, confirmações e contestações são simulações da interface e ficam em memória durante o uso.
